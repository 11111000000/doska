трекер обязательств

Кто кому что должен — один ответ для людей и агентов.

doska отвечает на один вопрос: кто кому что должен, в каком проекте, к какому сроку, в каком состоянии — и даёт всем сторонам один и тот же ответ. Написан на OCaml, состояние — в PostgreSQL, для агентов — MCP и bearer-токены, для людей — чат, веб и CLI.

правило, из которого выведено всё

Факт пересчитывается владельцем факта. Суждение живёт в трекере. Наблюдение — ссылка, а не копия. Ветка, PR и коммит — это evidence внутри задачи. Задача — обязательство.

границы

Жёсткие границы: doska не дублирует чужую работу

git считает факты, Teamboard измеряет, Mattermost разговаривает. doska — только обязательства. Наблюдение о внешнем мире — ссылка (evidence), а не копия.

решения владельца

Три решения, на которых всё держится

D1 · приёмка

Агент не закрывает свою задачу сам

Агент доходит до in_review и просит приёмки. Закрывает заявитель или руководитель; для доверенных проектов — режим autonomy='auto'. Правило R1 проверяется сервером, не честью.

D2 · единица работы

Задача = обязательство

Ветка, PR и коммит — evidence внутри задачи, а не отдельные единицы работы. Если правка превращает ветку в «задачу» — это неверно по определению.

D3 · Mattermost

Сначала бот-пут

Собственный webhook /hooks/mattermost: команды в чате, карточки с кнопками, личные сообщения из outbox. Go-плагин — поздняя волна, а не первый шаг.

попробовать

Поднять локально

Нужен Nix с флэйками — остальное он принесёт сам: OCaml 5.3, dune, зависимости.

# сборка и тесты
nix develop
dune build --root .
dune runtest --root .

# миграции и запуск
export DOSKA_DATABASE_URL="postgresql:///doska"
doska migrate --migrations-dir migrations
doska serve --port 8500

# живой API
curl -s -H 'X-Doska-Actor: petr' http://[::1]:8500/api/v1/tasks
