# Журнал решений

Append-only: запись не переписывается, новое решение — новая строка. Вопрос
«почему так» должен иметь ответ в репозитории, а не в памяти участника.

Кто принял:

- **владелец** — прямое решение человека;
- **владелец (указание)** — решение, оформленное по прямому поручению человека
  (например, «доделать» от 18.11.2026);
- **реализация** — техническое решение в рамках уже принятого; оно не меняет
  обязательств владельца и не требует его ревью.

## 19.11.2026 — решения по веб-фронтенду

| Решение | Суть | Кто | Почему | Где зафиксировано |
|---|---|---|---|---|
| **D4. Стек веб-фронтенда** | React, Vite и TypeScript убраны. Основа — веб-компоненты на чистом JavaScript (ES2022): Custom Elements, Shadow DOM, нативные ES-модули. D3.js — единственная runtime-зависимость | владелец (указание) | Фронтенд отражает функциональную дисциплину бэкенда, а не повторяет её в VDOM: чистые функции, неизменяемое состояние, ошибка — значение. VDOM и сборщик — лишний слой между моделью и DOM | ADR §6.4, §9.1, §9.2, §13 |
| **D3.js — единственная зависимость** | Библиотека подключается как leaf: рисует по данным, состояние не мутирует. Вход данных для визуализаций — `GET /api/v1/overview` и экран «Обзор» | владелец (указание) | Впереди «сложные достаточно навороченные визуализации» всего трекера; самописный SVG в таких задачах — источник багов, а тяжёлый фреймворк с собственным VDOM противоречит выбранной модели | ADR §6.4 |
| **Лёгкий фреймворк — допустим, но не обязателен** | Первый кандидат — Lit (~6 КБ, на веб-компонентах, без VDOM). Preact отклонён (VDOM дублирует модель), Alpine отклонён (директивы, а не компоненты). Любая новая зависимость — отдельная запись в ADR с обоснованием | владелец (указание) | Собственные компоненты на Custom Elements — минимальная база; фреймворк подключается только тогда, когда ручной код стал неподъёмным, и не молча | ADR §6.4, §13 |
| **Никакого сборщика** | Статика отдаётся сервисом как есть. `pnpm build` и nodejs в рантайме/деплое исчезают; node остаётся только в dev-оболочке — для тестов фронтенда (`node --test` над чистыми функциями) | владелец (указание) | Нативные ES-модули и веб-компоненты не требуют сборки. Узел в рантайме — ещё одна зависимость, которую надо обновлять и разворачивать | ADR §9.2 |
| **Тема — CSS custom properties** | Токены наследуются сквозь границу Shadow DOM; внешний доступ к частям компонента — `::part()` | реализация | Изоляция Shadow DOM иначе сделала бы тему невозможной: глобальные селекторы внутрь не проходят | ADR §6.4 |
| **Пересмотр источника для всех 32 claim'ов (правка ADR от 19.11.2026)** | `mathc map` → `mathc re-evaluate` → `mathc review-source` от имени владельца → `mathc run` | владелец (указание) | Правка ADR обнуляет ревью источника у всех claim'ов. Человеческий review не присваивает себе агент; основание — прямое поручение владельца от 19.11.2026 («внеси исправление в архитектуру фронтенда») | `spec.json`, поле `source.review` |
